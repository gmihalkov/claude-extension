# Trigger catalog

Each entry: when the trigger is present in the task, add its topic to the agenda. This file is yours to edit: add entries in the same shape.

- **Trigger:** roles are present. **Ask:** permissions: who sees what and who can do what; what a user without permission sees.
- **Trigger:** an entity has states. **Ask:** the state × action table: every cell is a requirement, an invariant, or a question.
- **Trigger:** users, data, network or external input are present. **Ask:** misuse scenarios: who must not be able to do what, each with a negative acceptance scenario.
- **Trigger:** a graphic source is present (mockup, screenshot, Figma). **Ask:** its strength level per dimension, then the per-element checklist.
